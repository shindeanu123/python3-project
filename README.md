# Quizverse

Quizverse is a quiz application built with Python. It stores its questions and data in a SQLite database and lets users answer questions and see their score.

## Files

- `Quizverse.py` - main program, run this file to start the quiz
- `questions.py` - the quiz questions and answers
- `database.py` - code that handles the database
- `quizverse.db` - database file

## How to run

1. Install Python 3
2. Download or clone this repository
3. Run:

   python Quizverse.py
